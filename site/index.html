One binary. Search, compare, and serve agents.

stdlib ServeMux, CGO SQLite, goose migrations, official MCP Go SDK. Kind e2e on every main push. 1.0 How it works →

Hybrid Hits
FTS5 BM25 always. sqlite-vec KNN when vectors exist. Reciprocal Rank Fusion k=60. match_source is fts | vector | both | rerank.
Catalog identity
Primary key is (catalog_id, resource_id). vec0 id is boverket:6000000000. REST databases= filters Catalogs — not a citation.
MCP tools
search_climate_data, get_resource_details, compare_resources on /mcp (streamable) and /mcp/sse.
Guard
MPP Authorization: Payment → HTTP 402. Unkey Bearer for developers. /healthz stays public. AllowAll until secrets are set.

The surface agents actually call. REST, MCP, then payment.
