One binary. Search, compare, and serve agents.

stdlib ServeMux, CGO SQLite, goose migrations, official MCP Go SDK. Kind e2e on every main push. 1.0 How it works →

Hybrid Hits
FTS5 BM25 always. sqlite-vec KNN when vectors exist. Reciprocal Rank Fusion k=60. match_source is retrieval fts | vector | both; rerank is a separate flag on the Hit.
Catalog identity
Primary key is (catalog_id, resource_id). Catalogs: boverket (JSON API) and dkbr (file; DatasetVersion BR18/BR25). br25 aliases dkbr. REST databases= filters Catalogs — not a citation.
MCP tools
search_climate_data, get_resource_details, compare_resources on /mcp (streamable) and /mcp/sse.
Self-hosted
Default binary has no Unkey and no MPP. /healthz and /api/* are ungated. The hosted build we run adds Guard via -tags hosted.
Operator console
html/template on the running process: Query, Data, Ingest, Webhooks, Lab. Open http://127.0.0.1:8080/ after make run. This Pages site is marketing only.
